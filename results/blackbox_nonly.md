## 해석

1. **실측에 맞추지 않은 음향만으로 실측 오차가 이전과 같은 수준입니다.** 블라인드 15.2(BX3)는 실측에 맞춘 음향의 V1(13.7)과 비슷하고, 같은 N만 라벨인 C2(24.9)보다 훨씬 낫습니다. DANN 11.2(BX4)는 실측에 맞춘 음향의 교차검증 DANN(Q3·Q4 11.4~12.5)과 같은 수준입니다. 실측 녹음을 음향 보정에 쓰지 않았으므로, 이 숫자에는 "평가 녹음에 맞춘 효과"가 들어 있지 않습니다.
2. **시뮬레이션 자체 평가는 나빠졌습니다(약 7 → 12).** 방·마이크·판 응답을 무작위로 바꾸면 음색과 음량 단서가 흐려지기 때문입니다. 실측이 어떤 방·마이크인지 모르는 상황의 정직한 불확실성입니다. σ도 이에 맞게 커져, 실측 오차가 1σ 안에 드는 비율이 33% → 60%로 올랐습니다 (이상값 68%).
3. **N만 라벨로도 재질에 따른 차이가 작습니다.** 지름·밀도 구간별 오차가 10~14로 비슷하고, 오차를 가르는 것은 이전처럼 층 수 F입니다. 벽 반발계수가 낮은 구간(0.3~0.55, lowe 데이터)만 16으로 나쁩니다.
4. **남은 문제: 많은 개수에서 과소 추정합니다.** N = 80~100 실측을 약 70으로 봅니다 (BX4 80~100 구간 오차 21.4). 블라인드는 15~45에서 과대 추정합니다 (N = 20 → 40).

## 학습 메모

- 검증 오차가 에포크마다 ±2 흔들려서, patience 8로는 학습률이 줄기 전에 멈췄습니다 (BX1 에포크 10, BX2 에포크 2). BX3·BX4는 30 에포크를 끝까지 돌리고 검증이 가장 좋은 에포크를 썼습니다.
- `merge_datasets.py`가 붙인 접두어("v3:") 때문에 합친 데이터에서 대조 쌍이 0개로 잡히던 버그를 고쳤습니다 (`train.py`). 이전 U1~U3 실험도 대조 쌍 손실 없이 학습되었습니다.

## 재현

```bash
# 시뮬레이터 (2-2-rne-simulation): 저장된 동역학으로 다시 합성
python scripts/rerender_blackbox.py <v3 runs 폴더> data/bbx/v3
python scripts/rerender_blackbox.py <lowe runs 폴더> data/bbx/lowe
# 머신러닝
python scripts/merge_datasets.py data/bbx_merged data/bbx/v3 data/bbx/lowe
rneml train --config configs/blackbox_nonly.yaml        # BX3
rneml train --config configs/blackbox_nonly_dann.yaml   # BX4
```

다시 합성한 소리는 Hugging Face `v3_bbx/`, `lowe_bbx/`에, 실험 결과와 모델은 `experiments/BX*`에 있습니다.
