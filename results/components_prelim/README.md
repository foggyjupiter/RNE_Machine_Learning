# 성분별 개수 정보량 분석 (예비: 시뮬레이션 v1 1744클립, 실측 300클립)

`rneml components`로 만든 결과. 소리를 주파수 대역 16개 × 성분 유형 11가지로 나누고, 성분마다 log(1+N)을 맞히는 R²를 잼.

- **sim_blind**: 시뮬레이션, 물질 모름 (실행 단위 교차검증)
- **real_cv**: 1차 연구 실측 녹음 안에서 (한 물질)
- **transfer**: 시뮬레이션으로 학습 → 실측에 적용

실측 녹음은 개수별 1~5번(100개)만 성분 선택에 쓰고, 6~15번(200개)은 검증에만 씀 (선택 편향 없음).

## 성분 유형별 R²

| 성분 | 시뮬레이션(물질 모름) | 물질 앎 | 처음 보는 물질 | 실측 안에서 | 시뮬→실측 |
|---|---|---|---|---|---|
| 클릭 음량 (perc_level) | **0.81** | 0.84 | **0.83** | 0.96 | 0.74 |
| 빠른 결 (20~50 Hz 변조) | 0.68 | 0.74 | 0.65 | 0.95 | 0.76 |
| 느린 변동 (0.3~2 Hz) | 0.67 | 0.68 | 0.69 | 0.86 | 0.76 |
| 충격성 (대역 첨도) | 0.61 | 0.66 | 0.62 | 0.96 | **0.89** |
| 음량 | 0.48 | 0.54 | 0.57 | 0.99 | 0.58 |
| 울림 음량 (harm_level) | 0.39 | 0.49 | 0.39 | 0.98 | 0.31 |
| 클릭 비율 (perc_share) | 0.41 | 0.45 | 0.19 | 0.96 | 0.17 |
| 음량 변동 | 0.33 | 0.34 | 0.27 | 0.96 | 0.40 |
| 충돌 검출률 | 0.33 | 0.34 | 0.18 | 0.92 | **−0.08** |
| 가진 주기 변조 (6.2 Hz 배음) | 0.45 | 0.57 | 0.30 | 0.75 | **−1.50** |
| 주기 접힘 (ψ1 일반화) | 0.31 | 0.40 | 0.21 | 0.57 | **−0.55** |

## 해석

1. **실측까지 통하는 개수 단서는 8 kHz 이상 대역의 충격성·클릭 음량·변조 결**이다. 2 kHz 이하 대역은 시뮬→실측 이전이 전부 음수(모터 잡음이 지배하고, sim2real 비교에서 0.5~2 kHz 차이가 있던 대역).
2. **가진 주기에 묶인 변조, 주기 접힘, 충돌 검출률은 시뮬레이션에만 있는 단서**: 시뮬레이션에서는 개수 정보가 있지만 실측으로 옮기면 R²가 음수. sim2real 비교에서 시뮬레이션의 주기성·충돌 수가 실측과 달랐던 바로 그 성분들이다.
3. 물질 의존: 물성을 알려 줘도 R²가 0.03~0.12만 오른다 → 성분 단위로는 물질의 혼동이 크지 않다. 처음 보는 물질에서도 클릭 음량·느린 변동·빠른 결은 그대로 버틴다.

## 검증 (선택에 쓰지 않은 실측 200개, N MAE)

| 사용한 성분 | 모델 | 시뮬 test | 처음 보는 물질 | **실측** |
|---|---|---|---|---|
| 전체 176개 | 부스팅 | 6.66 | 9.66 | 17.17 |
| **선택 40개** | 부스팅 | 8.49 | 10.21 | **8.99** |
| 음량만 | 부스팅 | 18.22 | 17.74 | 24.28 |
| 음량 제외 | 부스팅 | 7.32 | 9.63 | 18.41 |
| 전체 176개 | 릿지 | 7.36 | 9.01 | 21.55 |
| **선택 40개** | 릿지 | 11.24 | 11.55 | **11.85** |

→ 실측에서 통하는 성분만 남기면 **실측 오차가 절반**(17.2 → 9.0)으로 준다. 시뮬레이션 성능은 조금 잃는다(6.7 → 8.5). 시뮬레이션에서 가장 정확한 특징 조합이 실측에서 가장 좋은 것은 아니다.

CNN 실험: B9(선택 성분), B11(8 kHz 이상 이미지 + 선택 성분만, 시뮬레이션 전용 단서 제거), B12(B11 + 비지도 실측 적응). 데이터가 다 모이면 전체 데이터로 이 분석을 다시 하고 대조 쌍 기반 "개수 특이도"도 계산한다.
