# rneml — 물질을 몰라도 충돌음으로 개수와 물성 추정하기

밀폐 용기를 흔들 때 나는 충돌음만 듣고 **안에 든 입자의 개수 N**과 **입자 물성(지름, 밀도·질량, 반발계수, 마찰계수, 탄성률)**을 함께 추정하는 모델입니다.

1차 연구([2-1-CNN-](https://github.com/foggyjupiter/2-1-CNN-))는 같은 BB탄만 썼기 때문에 "물질을 이미 안다"는 전제가 있었습니다. 이번 연구는 그 전제를 없애는 것이 목표입니다.
실험만으로는 물성을 바꿔 가며 정확한 라벨을 붙이기 어려우므로, 시뮬레이터([2-2-rne-simulation](https://github.com/foggyjupiter/2-2-rne-simulation))로 만든 데이터([FoggyJupiter/rne-granular-acoustics](https://huggingface.co/datasets/FoggyJupiter/rne-granular-acoustics))로 학습하고, 1차 연구의 **실제 녹음**으로 검증합니다.

## 설치

```bash
pip install -e ".[dev]"
```

Python 3.10 이상, PyTorch 2.2 이상. GPU가 있으면 자동으로 씁니다.

## 사용법

```bash
rneml fetch --dir data/v1                       # 시뮬레이션 데이터셋 다운로드 (약 3 GB)
rneml train --config configs/blind.yaml --real-dir ../2-1-CNN-/data-all
rneml train --config configs/bb_baseline.yaml --real-dir ../2-1-CNN-/data-all
rneml evaluate outputs/blind_mel --real-dir ../2-1-CNN-/data-all
rneml train --config configs/blind.yaml --seed 1 --name blind_mel_s1     # 앙상블용 다른 시드
rneml ensemble outputs/blind_mel outputs/blind_mel_s1 --name ens_mel --real-dir ../2-1-CNN-/data-all
rneml report outputs/*                           # 실험 비교표 (markdown)
rneml predict 새녹음.wav --run outputs/blind_mel [--run outputs/blind_scalogram]   # 새 녹음 추정
```

`rneml predict` 출력 예:
```
새녹음.wav: N = 42.3 ± 4.1
    diameter  6.2 mm  (1σ: 5.8 – 6.6)
    density   1.1e+03 kg/m3  (1σ: 900 – 1.4e+03)
    e_pw      0.78 -  (1σ: 0.7 – 0.86)
    ...
```
새 녹음은 학습 데이터와 같은 조건이어야 합니다: 5×5×7 cm 상자, 372 rpm, 휴대폰 마이크 약 2.7 m.

GPU가 없으면 `--width 16 --time-pool 2`를 붙이세요. 너비를 절반으로 줄이고 프레임을 20 ms로 묶어 약 9배 빨라집니다 (CPU 1스레드 기준 샘플당 0.31초 → 0.035초).

`--real-dir`에는 1차 연구의 5초 클립 폴더(`{개수}-{번호}.wav`)를 줍니다. 비공개 저장소라면 `huggingface-cli login`을 먼저 하세요.
특징은 처음 한 번 계산해 `cache/`에 저장합니다.

| 설정 | 학습 데이터 | 목적 |
|---|---|---|
| `configs/blind.yaml` | 모든 물성 | **물질을 모르는** 추정기 (본 모델) |
| `configs/blind_scalogram.yaml` | 모든 물성, 웨이블릿 스케일로그램 입력 | 1차 연구 최고 표현(웨이블릿)과 멜 비교 |
| `configs/blind_dann.yaml` | 모든 물성 + 실측 녹음 개수별 5개 (**라벨 없이**) | 정답 없이 실측 소리만으로 시뮬레이션-실측 차이를 줄일 수 있는지 (나머지 10개로 평가) |
| `configs/blind_real_adapt.yaml` | 모든 물성 + 실측 녹음 개수별 5개 (라벨 포함) | 실측 몇 개에 정답을 붙이면 얼마나 좋아지는지 (나머지 10개로 평가) |
| `configs/bb_baseline.yaml` | **물질 고정 동반 데이터셋** `bb_fixed/` (1차 연구 BB만: 6 mm, 0.12 g, e = 0.8) | 1차 연구처럼 물질을 고정해 학습한 모델이, 물질이 바뀐 테스트셋에서 무엇이 깨지는지 보여 주는 비교 기준 (평가는 본 데이터셋) |

## 방법

**입력**
- 48 kHz 로그-멜 스펙트로그램 (128 밴드, 50 Hz~24 kHz, 10 ms 간격). 충돌 에너지 대부분이 8~24 kHz에 있습니다. 1차 연구는 22.05 kHz로 리샘플해서 이 대역 절반을 버렸습니다.
- dB 기준값을 고정해 절대 음량을 보존합니다 (1차 연구와 동일).
- 물리 특징 12개: 음량 통계, 스펙트럼 변화량, 활성 프레임 비율, 파형 첨도(ψ3), 스펙트럼 엔트로피(ψ2), 가진 주기로 접은 에너지의 뾰족함, 무게중심, 고역 충돌 검출률, RMS, 클리핑 비율
- **변조 스펙트럼** 192개 (`use_modulation`): 멜 대역을 16묶음으로 나누고, 각 묶음의 음량이 시간에 따라 어떤 주기로 출렁이는지(0.8~50 Hz, 12구간)를 잽니다. 가진 주파수 6.2 Hz와 배음, 충돌 빈도의 결이 여기에 나타납니다. 1차 연구의 ψ1(주기 앞/뒤 에너지 비)과 위상 집중도를 **위상 기준 없이** 일반화한 것입니다. 상대 변동만 보므로 마이크 게인이나 질량이 바꾸는 음량에 영향을 받지 않습니다.

**입력 표현** (`feature`): `mel` 또는 `scalogram` (모를레 웨이블릿, 상수 Q 64밴드 100 Hz~22 kHz, 10 ms 프레임). 1차 연구에서는 웨이블릿이 가장 좋았지만 8 kHz로 낮춰 계산했습니다. 여기서는 전 대역을 씁니다.

**물성은 절대 입력이 아닙니다.** 지름·밀도·반발계수·마찰·탄성률은 모두 맞혀야 할 출력이고, 모델이 받는 것은 소리뿐입니다.

**모델** (`rneml/model.py`)
- CNN(채널 32-64-128-128) → 주파수 평균 → 시간축 통계 풀링(평균·표준편차·최댓값) + 물리 특징 → MLP
- 출력 헤드 (모두 **회귀**, 각각 평균과 불확실성 σ):
  - **개수 N**: 0~100을 1개 단위로 연속 추정합니다. 분류(5개 단위 21클래스)가 아니라 회귀인 이유는 두 가지입니다. N에는 순서가 있고, 1차 연구 보간 실험에서도 회귀가 학습에 없던 개수까지 맞혔습니다.
  - **물성 8개**: 지름, 밀도, 질량, 반발계수(입자끼리·입자-벽), 마찰계수(입자끼리·입자-벽), 탄성률
- 불확실성 σ: "작은 입자 여러 개"와 "큰 입자 몇 개"처럼 소리가 비슷한 영역에서 모델이 확신 없음을 표시하게 합니다. 평가에서 오차가 1σ 안에 드는 비율(이상적으로 68%)로 보정 상태를 확인합니다.

물성을 함께 맞히게 하는 이유: 소리는 (1 − e²)·N 같은 **조합**에 반응합니다 (1차 연구의 스케일링 Γc ∝ (εF)²). 물질을 알아볼 수 있는 모델이어야 물질의 영향을 개수에서 떼어낼 수 있습니다.

**손실** (`rneml/train.py`)
- N: Huber 손실 (N/100 스케일)
- 물성: MSE (정규화된 값). 실측 녹음은 BB의 지름·밀도·질량만 알고 나머지는 마스크합니다.
- 불확실성: 가우시안 NLL. 평균에는 기울기를 막아서, σ가 평균을 끌어당기지 않고 평균이 얼마나 틀리는지만 배웁니다.
- **같은 N·다른 물성 쌍**: 두 예측이 같아지도록 (불변성)
- **같은 물성·다른 N 쌍**: 순서가 맞도록 (마진 순위 손실)
- 증강: 시간 크롭(클립의 80%), SpecAugment, 음량 ±3 dB 이동. 음량은 질량·마이크 게인과 얽혀 있어서 음량 하나에만 기대지 못하게 합니다.
- **비지도 실측 적응 (DANN)**: 라벨 없는 실측 녹음을 배치에 섞고, 내부 표현에서 시뮬레이션/실측을 구별하는 판별기를 기울기 반전층 뒤에 둡니다. 모델은 판별기를 속이는 방향, 즉 두 도메인을 구별할 수 없는 표현을 배웁니다. 시뮬레이션에만 있는 단서(알려진 sim2real 차이)에 기대지 못하게 하려는 장치입니다.

**음량 무관 옵션** (`level_free: true`): 클립마다 평균 dB를 빼고 음량 특징을 0으로 둡니다. 마이크나 녹음 거리가 바뀌는 상황에 대비한 비교 실험용입니다. 대신 음량에 담긴 개수 정보도 잃습니다.

**추론**
- 테스트 시 평균(TTA): 전체 클립과 80% 크롭 4개의 예측을 평균합니다.
- σ 사후 보정: 학습 후 검증셋에서 (오차/σ)² 평균이 1이 되도록 각 출력의 σ 배율을 맞춥니다.
- 앙상블 (`rneml ensemble`): 여러 시드나 입력 표현의 모델을 평균합니다. 불확실성은 각 모델의 σ와 모델 간 의견 차이를 합친 값입니다.

## 평가 (`rneml/evaluate.py`, `outputs/<이름>/metrics.json`)

| 항목 | 의미 |
|---|---|
| `test` | 학습과 같은 물성 분포, 처음 보는 실행 |
| `test_ood` | **학습에 없던 물성 영역** (밀도 2800~4000 kg/m³ 이면서 입자-벽 반발계수 0.55~0.68) |
| `test_by_material` | 지름·밀도·반발계수 구간별 N 오차 (물질에 따라 오차가 평평한가) |
| `same_N_pair_gap` | 같은 N·다른 물성 쌍의 예측 차이 |
| `properties_test(_ood)` | 물성별 오차(실제 단위)와 R² |
| `degeneracy_test(_ood)` | **"작은 입자 여러 개 vs 큰 입자 몇 개" 혼동 진단**: N 오차와 지름·밀도·질량 오차의 상관 (지름과 음의 상관이면 그 혼동이 있다는 뜻), N의 상대 오차 vs 층 수 F = N d²/A의 상대 오차 (F가 훨씬 정확하면 혼동이 층 수를 따라 일어남) |
| `real` | **1차 연구 실제 녹음**(BB, 0~100개, 개수별 15개)에서의 N 오차. 시뮬레이션만으로 학습한 모델이 실측에서 통하는지 |
| `real_properties` | 실제 녹음에서 추정한 물성과 실제 BB 값(6 mm, 0.12 g) 비교. 반발계수는 실측값이 없으므로 추정치만 보고 |

지표: MAE, RMSE, 편향, ±5개 이내 비율, ±10개 이내 비율 (1차 연구의 ±1, ±2 클래스에 해당).
그림: `pred_vs_true.png` (예측-정답, ±σ), `properties_test.png` (물성), `real_by_N.png` (실측 녹음 개수별 평균 예측), `error_by_material.png` (N 오차 vs 지름·밀도·반발계수).
실측 녹음은 적응에 쓴 클립(라벨 유무와 관계없이)을 평가에서 항상 뺍니다.

## 주의

- 같은 동역학 실행에서 나온 클립 4개는 독립이 아닙니다. 데이터셋의 `split` 열은 실행 단위로 나뉘어 있으니 그대로 쓰세요.
- 시뮬레이션과 실측 사이에는 알려진 차이가 있습니다 (개별 충돌이 더 많이 들림, N = 100 주기성 등). 자세한 내용은 시뮬레이터 레포의 `results/sim2real/`에 있습니다.
- 지름을 모르면 "작은 입자 여러 개"와 "큰 입자 몇 개"가 섞이는 영역이 생길 수 있습니다. `test_by_material`과 물성 R²로 확인하세요.
